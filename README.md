## 🚀 What Is This Project?

Deep Space 3D Live Tracker is a real-time interactive 3D visualization of our Solar System that tracks NASA's most famous deep-space missions.

You can rotate, zoom, click on any spacecraft and see its live distance, speed, and status - just like NASA's Eyes on the Solar System.

Built as a **BTech Final Year Project** using only Web Technologies - No installation needed, runs in browser.

## ✨ Features

- **Interactive 3D Solar System** - Drag to Rotate, Scroll to Zoom
- **Click to Focus** - Click any probe card or 3D object to focus camera
- **Live Distance Counter** - Distances increase every second in real-time
- **Live ISS Tracking** - Real ISS Latitude / Longitude from Open Notify API
- **Realistic Orbits** - Planets, Probes & ISS orbiting with correct relative speeds
- **Info Panel** - Click any spacecraft to see its full mission story
- **Pause / Play & Reset View** - Full control over simulation
- **Mobile Friendly** - Works on Phone + Laptop

## 🛠️ Tech Stack

- **HTML5 + CSS3** - UI & Layout
- **JavaScript** - Logic & Live Updates
- **Three.js** - 3D Rendering, Orbit Controls, Lighting
- **NASA JPL Data** - Real Distances & Speeds
- **Open Notify API** - Live ISS Location

---

## 🎮 How To Use

1. Open Live Demo link
2. **Drag** - Rotate Solar System
3. **Scroll** - Zoom In / Out
4. **Click Probe Card** on right side - Camera will fly to that spacecraft
5. **Click 3D Object** directly - Show mission info
6. **Reset View** - Go back to full Solar System view
